# N6「方程」SPEC

方向见 [STORYLINES](STORYLINES.md) A。时刻以 build.py 输出为准，本表为约值。

- GOAL：看完能说出「照片、修图、推荐、AI 底下都是矩阵；它起源于两千年前的算板；几乎所有大计算最后都化成解方程组」，并且每一章都有一个自己想通的瞬间
- OUTPUT：HyperFrames，1920×1080，60fps，纯 2D canvas（3D 物件为自写投影）
- TIME：96 BPM，一小节 2.5s；段落边界落在小节线上；全片约 12 分钟，分 8 章

## 1. 讲法

- 每章三步：**直觉物件**（天平、橡皮筋、修图按钮、翻书、地球仪、硬币、口味坐标）→ **同一件事的矩阵画法** → **应用**。名词与公式只在观众已经看懂之后出现，作为「刚才那件事的名字」
- 每章只有一个贯穿的例子（第一题的三捆禾、谷神星、那只猫、那本书、8 个网页、那张照片、两团缠在一起的点），从头算到尾，不换例子
- 世界只有一张长桌：6 张书桌首尾相接（每张 32×18 单位，s=60 px/单位时恰好一屏），x 方向即时间。摄像机只有中心 c、缩放 s，缩放按对数插值，整片不切镜头
- 一根算筹 = 一个向量：汉代摆数的算筹，在后面网格里就是两根基向量（朱红 = 第一列，墨色 = 第二列）
- 道具有来有去：直觉物件从画外滑上桌面，用完滑走；概念在每张桌的「工作台」里演（漆算板、星图、方格纸、笔记本、绿条打印纸、平板）

## 2. 观感

- 俯拍平铺：光从左上，器物投影偏移 (0.12, 0.18) 单位、模糊 0.3 单位、不透明度 0.35；扁平色块 + 一条亮边
- 桌面：汉 竹席 #CDB27A、1801 胡桃木 #4A3324、1858 绿皮革 #2F5242 + 金边、1925 橡木 #B98C5A、1998 灰色防火板 #8E949A、今天 白桦 #E6DCCB
- 朱红 #D9452E 是唯一强调色，每一刻只给一个焦点
- 画面大字 Noto Sans SC 700 / 54px，下方居中 y≈868；按背景取墨色 #1E2638 或纸色 #F4EFE4，配反色柔和投影；逐字显出（每字错开 0.035s），整行 0.3s 淡出。数字与矩阵用 JetBrains Mono，公式用 KaTeX 字体
- BANNED：深色虚空里漂浮小元素、辉光粒子、玻璃卡片、三卡并排、所有元素一起淡入上滑、阅读中文字移动、角标装饰、未解释的公式

## 3. 章节

| 章 | 约时长 | 桌 | 直觉 → 矩阵 → 应用 | 「原来如此」 |
|---|---|---|---|---|
| 0 照片 | 20s | 今天 | 手机照片推近 50 倍，变成一格格 RGB 数字；拉远见整张两千年长桌 | 照片就是一张数表 |
| 1 方程术 | 80s | 汉 | 三条线索是三架平衡的天平 → 线索二放大三倍、两次拿掉线索一，上禾整个消失 → 古人把天平写成一列算筹，遍乘直除算到 36 \| 99 → 答 9¼、4¼、2¾ 斗 | 两边拿掉一样的东西还平衡；照步骤做一定算得出，这就是算法 |
| 2 谷神星 | 65s | 1801 | 谷神星跟丢；带误差的点不存在穿过所有点的轨道 → 每个点用橡皮筋拴住轨道，轨道被拉到平衡（能量 ∝ 伸长²，画成小方块）→ 平衡条件又是方程组，消元 → 年底重现 | 最好的答案 = 小方块总面积最小 |
| 3 矩阵会动 | 100s | 1858 | 平面上任一点 = 几根红棍 + 几根黑棍 → 只要说清两根棍落到哪，整张网格和猫都跟着走（两列数）→ 修图按钮：放大、旋转、斜切、镜像 → 两步并一步 = 矩阵乘法 → 猫的面积 = 行列式，镜像为负，压扁为 0 → 两个未知数的方程组 = 「谁变形后落在 b」，压扁时无解或无穷解 | 2×2 的四个数，管住整个平面 |
| 4 顺序 | 70s | 1925 | 桌上的书：先前翻再右转 ≠ 先右转再前翻 → 猫：先转后推 ≠ 先推后转 → 海森堡的原子数表，玻恩认出是矩阵，xp − px = iħ → 不确定性原理、芯片与激光 | 乘法顺序不能换，世界就是这样的 |
| 5 排名 | 95s | 1998 | 俯拍地球仪自转，只有北极点不动 → 网格变形，只有两个方向不拐弯 → 一根箭头反复变形，被拉向同一方向 → 8 个网页上随手点链接，访问比例收敛；从两个不同网页出发，收敛到同一组比例 → 1998 年 Google 用它排 2400 万个网页 | 反复做同一个变形，最后剩下的就是特征向量 |
| 6 照片怎么变小 | 80s | 今天 | 87 元：87 枚一元 vs 50+20+10+5+1+1 → 一行 8 个像素，用平均 + 缓坡 + 波纹积木，只剩两个大数 → 8×8 块用 64 块积木按之字顺序拼回，大部分权重≈0 被划掉 → JPEG 约十分之一 | 换一套积木（基），大多数数就变成 0 |
| 7 AI | 120s | 今天 | 口味坐标：你和电影都是点，近 = 口味像，这就是推荐 → 打分 = 对应相乘再相加，一亿人 × 一万部电影 = 一次矩阵乘法 → 词也是点，男→女是同一根箭头：国王 − 男人 + 女人 ≈ 女王 → 两团缠在一起的点，一刀切不开；一层 = 矩阵变形 + 一次弯折，几层之后一刀切开 → GPT-3 1750 亿个参数，每出一个字做上千亿次乘加，显卡为此而造 | 神经网络就是一层层把空间揉开 |
| 8 地基 | 60s | 今天 → 汉 | 一块受热的铁板切成格子，每格温度 = 四邻平均，一格一个方程 → 一万格一万个方程，算板裂成成百上千列 → 天气、CT、桥梁、芯片、新药 → 全球超算排名比的就是解 Ax = b → 倒飞回汉代，算筹收回空板，片名「方程」 | 现代科学的大计算，最后都落到解方程组 |

- 章间平移到下一张桌（2.5s，途中缩放降到 34，快动加运动模糊）
- 强手法：第 0 章拉远见全桌、第 4 章书的 3D 翻转、第 8 章倒飞
- 示意数据：谷神星观测点、网页链接图、口味与词向量位置、缠绕点为示意，画面注「示意」；《九章》第一题、正规方程、PageRank、DCT 系数均为实算

## 4. 声音

- 动机：五声音阶 E D C · D E C · C D E · G（取自第一题系数），乐器随桌换：古琴、羽管键琴、八音盒、钢琴、方波、合成器
- 动作音：算筹落板、天平摆动、橡皮筋、翻书、地球仪、硬币、键鼠、手机触感；数值每变一次一声；随手点链接每跳一次一声，越点越快
- 声画同源：第 3 章持续音音高随猫的面积（行列式）变化，压扁到 0 时一声闷响；第 6 章每拼上一块积木一声，被划掉的积木静音

## 5. 校验

- build.py：消元逐步模拟并与《九章》答案对照；最小二乘与 numpy 一致、总面积单调下降；PageRank 和为 1，两个起点的访问比例都收敛到它；DCT 重建误差；字幕停留 ≥ 阅读时长、互不重叠；同桌器物包围盒不重叠
- check.mjs（逐帧 30Hz）：镜头参数有限；运动模糊子帧数 ≤ 16；道具滑入滑出不与桌上器物重叠
