# N6 线性代数科普：故事方向

受众：被手机、导航、AI 包围的高中 / 大学学历观众。目标：看完知道「线性代数是什么、从哪来、为什么撑起了现代科学」。无旁白，画面文字 + 程序化音乐音效。

用户要求一直做到成片，按 skills 约定取推荐方向 A 直接做。

## A「两千年的桌子」（选定）

- 装置 + 形式：一张很长的桌子，从左到右是六个时代的书桌（汉、1801、1858、1925、1998、今天），摄像机沿桌子走，就是穿越时间；每张桌上的「工作台」（算板、星图、方格纸、笔记本、打印纸、手机）里讲透一个概念
- 开头：手机里一张照片放大成一格格 RGB 数字 → 拉远看见整张两千年的长桌 → 落到汉代算板
- 节拍：照片是数表 → 九章方程术（消元）→ 高斯找回谷神星（最小二乘）→ 凯莱：矩阵 = 变形、行列式 → 海森堡：乘法顺序不能换 → Google：特征向量排网页 → 今天：JPEG 换基、AI 词向量与层层矩阵 → 超算排名考的还是解方程组 → 回到算板，片名「方程」
- 观感：平铺摄影（flat lay）式俯拍插画，每个时代一种桌面材质与器物；唯一强调色是汉代漆器的朱红
- 声音：同一个五声动机贯穿，乐器随时代换（古琴 → 羽管键琴 → 八音盒 → 钢琴 → 芯片方波 → 合成器）

## B「拆开你的手机」

无尽推近：照片 → 像素 → 数表；地图 → GPS 方程组；推荐 → 特征向量；AI → 矩阵层；推到最底层，是一块汉代算板。手机一镜到底，历史只在最底层出现，「如何发展」讲得弱。

## C「一张网格的一生」

主角是一张会动的方格纸，它学会拉伸、旋转、压扁、翻转，每学会一招就解锁一个现实应用；大字排版驱动，最抽象也最大胆，但离观众的生活最远。
