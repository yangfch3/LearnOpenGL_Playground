故事线见 [STORYLINES](STORYLINES.md)。下集镜头见 [SPEC-下](SPEC-下.md)，通用部分只写在本文 §1–§8。
动手前先读：[制作 CheckList](../../docs/制作CheckList.md)、[创作原则](../../docs/创作原则.md)、[工程约定](../../docs/工程约定.md)、[风格规范](../../docs/风格规范.md)、[探针记录](../../docs/试点/探针记录.md) 的 N4–N7 节。

## 1. 目标与受众

- 受众：受过高中或大学教育、天天用手机和 AI，但没系统学过线性代数（或早已忘了）的人
- 上集看完能说出：矩阵就是我学过的方程组、坐标、向量装进一张表；它能让整张坐标纸变形；行列式为 0 时方程没有唯一解
- 下集看完能说出：滤镜、Google、AI 底下都是矩阵；造它们靠解方程，用它们靠乘矩阵
- 片长：上集约 8 分钟，下集约 9.5 分钟；以 build.py 按阅读时长排出的结果为准，不为凑时长加戏，也不为压时长删字

## 2. 全片规则

- **一道题贯穿**：鸡兔同笼（《孙子算经》，约 1600 年前：「今有雉兔同笼，上有三十五头，下有九十四足」，答鸡 23、兔 12）。每段只推进一步，下一段必须用到上一段的东西
- **课本记号原样出现**：大括号方程组、①②编号、y = kx + b、(x, y)、带箭头的向量 $\vec a$、回归方程 $\hat y=\hat b x+\hat a$。新名词（矩阵、线性变换、行列式、矩阵乘法）只在观众看懂那件事之后出现，作为它的名字
- **每段一个本质、一个装置**：镜头表里每行写了「本质」，画面只服务这一句；说不出理由的动作不加（创作原则 §2-7）
- **不提学段**：字幕与纸上文字不出现小学、初中、高中、大学等字眼；学段只靠纸的样式（翻页换纸）暗示
- **字少**：无旁白。一条字幕只讲一件事，≤ 18 字；能写在纸上的（算式、坐标、标注）写在纸上，不进字幕
- **喘息**：1-post、2-post（以及下集的喘息段）几乎无字，镜头慢，音乐留白，给观众消化
- **不按年代排**：历史只出现两次：开头标注题目出处，下集结尾的倒放

## 3. 世界与观感

- **世界**：书桌上一本摊开的数学本，从小学用到大学。全片在这一个场景里完成（创作原则 §7「一个世界演到底」）。学段推进 = 翻到下一页，纸的样式随之变：

| 矩阵 | 大学草稿纸，同上方格 | 蓝黑墨水 |

- 对比度门槛（风格规范 §1）：文字 ≥ 4.5:1，图形 ≥ 3:1，对纸色实算；不达标就加深，不改语义
- **字体**：底部字幕 Noto Sans SC 700 / 52px，墨色，加纸色柔光描边；标题卡（胶带上的手写大字，110px）与批注（底部偏右、微斜的手写小字，50px）用霞鹜文楷；点题词红字加荧光笔底，字幕与纸上同词同样式；纸上手写用霞鹜文楷（LXGW WenKai，OFL 1.1，保留字体名不改名；放 `shared/fonts/`，走 LFS，附 OFL.txt）；课本印刷体公式用 KaTeX 字体；不另用等宽字体
- **动物**：小学课本插图式简笔画，侧面，2–3 个平涂色 + 3px 铅笔描边；不画写实毛发。鸡「抬两只脚」= 蹲坐（双脚收起），兔「抬两只脚」= 后腿站立
- **光**：桌面与纸面俯拍为主；纸上的物体（翻起的纸页、三维平面、楼）投影从左上来
- **BANNED**：spec.md 的默认禁用项（深色虚空、辉光粒子、玻璃卡片、三卡并排、一齐淡入上滑、阅读中的文字乱动（跳动、变形、变化太快；平稳地跟着画面物体走不算）、角标装饰）；未解释的公式；一条字幕两个概念；量子力学；任何模型或公司的 logo；只用 ChatGPT 代表 AI；按年代平铺
- **示意数据**：外卖、网页链接、词向量、颜色偏差等示意数据，纸上角落标「示意」

## 4. 相机与渲染

- **一台相机、一组参数**（工程约定 §3）：画面中心、纸面半高（缩放）、k = 1/视距（k = 0 正交）、偏航、俯仰。平面段：俯仰 0、k = 0，正交俯拍纸面；三维段：同一相机抬起俯仰、k 渐增转为透视。缩放按对数插值，运镜是首尾相接的缓动段
- **渲染**：Three.js（渲染加 `--experimental-fast-capture=false`）。纸面内容画在 canvas 上贴到纸面网格；正交俯拍段也可以直接在屏幕空间画，但两种方式必须用同一投影公式，交接帧逐像素对齐（成片抽帧实测，工程约定黄金准则 5）。纸面字在任何缩放下都要清晰，纹理分辨率按当前「屏幕像素 / 纸面单位」取
- **翻页**：纸页绕书脊旋转 180°，是同一场景里的三维动作，0.9s，带投影
- **快动**：每帧位移超过约 15px 且有大块深浅对比时加子帧运动模糊（工程约定 §3）；峰值不超过 48px/帧
- **版式**：1920×1080；字幕带中心 y = 868；字幕显示时，纸上的标注与焦点不得进入 y ≥ 800 的区域；内容在 90% 动作安全框内，字幕在 80% 标题安全框内

## 5. 声音

- 程序化背景音乐（N 系列例外，见预研 §6）：90 BPM，一小节 2.667s；段落起点落在小节线上
- 一个主题旋律贯穿两集：童谣式五声音阶短句。音色随学段加厚：小学八音盒 → 初中钢琴 → 高中钢琴 + 弦垫 → 矩阵段加低音合成垫；喘息段只留弦垫
- 动作都有声音，落点取自 build.py 节拍：书写（长度 = 书写时长；上集为铅笔沙沙，下集改为平滑低频的软笔声）、翻页、动物（轻巧的拟声小音，不用真实鸡叫录音）、箭头首尾相接（每接一根一声，音高随序号升）、网格变形（持续音，音高随行列式；压扁到 0 时一声闷响，同 N6 的做法）、点落定、红笔圈画
- 混音：综合响度约 −20 LUFS（±1），真峰值 ≤ −1 dBTP；成片后用 ffmpeg ebur128 实测，不达标调总增益重出

## 6. 工程

- 一个工程 `pilot/N7-hyperframes/`，两集共用同一套场景代码与文本表；`build.py --ep 1|2` 生成对应集的数据、音轨与 `index.html`，输出 `renders/N7-ep1.mp4`、`renders/N7-ep2.mp4`。下集倒放直接取两集成片片段倒放（见 SPEC-下 §4 的 7），每段场景仍按「段内时刻」独立画出，不依赖之前的帧
- 单一时间源：build.py 算出全部节拍（按字幕阅读时长排，同 N6 的 `TL.say` 做法）、几何、实算数据、音轨；HTML 与 JS 不写时间常数
- 可校验逻辑（相机、矩阵插值、动物位置、标注包围盒）写成无 DOM 纯模块，浏览器与 check.mjs 共用
- 文本：字幕与纸上文字全部在 `assets/text/zh-CN.js`，按键取用
- 代码按段拆模块，单文件不超过约 400 行

## 7. 校验

- build.py 断言：本 SPEC 每段「数据」列列出的等式；字幕停留 ≥ 阅读时长且互不重叠；镜头段首尾相接不交叠；段落起点在小节线上
- check.mjs 逐帧（30Hz）：相机参数有限且个数完整；每帧位移与子帧数匹配；纸上标注包围盒互不重叠、不进字幕带、不出纸面；动物彼此不重叠、不出笼子
- 成片后：ffmpeg 抽帧复核改过的地方与二维↔三维交接帧；ebur128 测响度；signalstats 查任意 1 秒内亮度大跳变 ≤ 3 次（光敏底线）

## 8. 流程

1. 先做样片：上集 2d 末尾 + 2e 全段（约 60s，含网格压扁、两线重合 / 平行的回扣），交用户看，认可后再做整片（制作 CheckList §1）
2. 上集整片：build → check → 每段抽 1–2 帧拼图审 → 渲染 → 抽帧复核 → 交付
3. 下集同上；倒放段最后做，单独抽帧审
4. 过程与踩坑记入探针记录 N7 节

## 9. 上集镜头

时长为约值。「纸上」指写或画在纸面上的内容（手写体或印刷体），不进字幕。字幕一行一条，按顺序出现。

### 0 开场（约 10s）

- 相机：俯拍，书桌上一部手机斜放在合着的数学本上
- 画面：
  1. 0–3s：手机屏幕快速轮换三个画面：对话窗（标题依次 GPT、Claude、DeepSeek，只写文字名）、搜索结果、修图滤镜滑杆
  2. 3–6s：屏幕像素裂开成一格格数字，数字从屏幕溢出到本子封面
  3. 6–8s：数字收拢成 4 个，排成 2×2：1 1 / 2 4（第一列鸡色、第二列兔色）
  4. 8–10s：一只简笔兔子从数字后面探出头；本子翻开到第一页
- 字幕：「鸡兔同笼，和 AI 用的是同一种数学」
- 第 0 帧就是缩略图：手机里的对话窗 + 本子，不能是黑屏或空桌

### 1a 小学 · 抬脚法（约 40s）

- 相机：正交俯拍横线算术本
- 画面：
  1. 铅笔在纸上画出一个笼子，35 只动物（23 鸡 12 兔，打乱排成 7×5）依次跳进去；纸上角写「《孙子算经》约 1600 年前」
  2. 纸上写「35 个头，94 只脚」
  3. 所有动物同时抬起两只脚：鸡蹲坐，兔后腿站立。地面上还着地的脚逐只亮起红笔小点，计数 0 → 24
  4. 纸上写：24 ÷ 2 = 12（兔），35 − 12 = 23（鸡），红笔圈出答案
- 字幕：「35 个头，94 只脚：鸡兔各几只？」「最老的办法：每只都抬起两只脚」「地上剩 24 只脚，全是兔子的」
- 数据：23 + 12 = 35；2·23 + 4·12 = 94；抬脚后着地 = 94 − 2·35 = 24
- 声音：八音盒主题起；每只动物跳进一声；抬脚一齐「噗」；计数逐声升调

### 1b 初中 · 方程组（约 30s）

- 相机：翻页到方格本，正交俯拍；1a 的笼子缩小留在左页
- 画面：
  1. 右页手写「设鸡 x 只，兔 y 只」，再写大括号方程组 ① x + y = 35、② 2x + 4y = 94
  2. 写「② − ① × 2」，下一行 2y = 24，y = 12，x = 23
  3. 左页的抬脚动画缩略重放一遍，与「② − ①×2」那一行用红笔连线
- 字幕：「换个写法：设鸡 x 只、兔 y 只」「方程②减去两个方程①，y 就露出来了」「这一步，就是刚才的抬脚」
- 数据：② − 2·① = (0, 2 | 24)

### 1c 初中 · 两条直线（约 45s）

- 相机：同页向下平移到坐标纸区域，横轴 x（鸡）、纵轴 y（兔），各 0–40
- 画面：
  1. 画出直线 x + y = 35（鸡色），标注①
  2. 一个红笔小点沿这条线从 (35, 0) 滑到 (0, 35)，旁边跟一个小标签「x 鸡 y 兔 · 脚 2x+4y」，数字随滑动实时变（只取整数点时跳一下）
  3. 画出直线 2x + 4y = 94（兔色），标注②
  4. 小点滑回，在交点 (23, 12) 停住，标签的脚数正好 94；红笔圈出交点
- 字幕：「每个方程，都是坐标系里的一条直线」「沿着这条线走，头总是 35 个，脚在变」「两条线的交点，就是答案」
- 数据：两线交点 (23, 12)；滑动时每个整数点的脚数 = 2x + 4y

### 1d 高中 · 三维（约 40s）（三维段 1）

- 相机：方格纸从桌面立起，相机抬起俯仰、转为透视，绕到斜上方
- 画面：
  1. 笼子里又飞进几只蜻蜓；纸上写三元方程组：头 x + y + z = 12、脚 2x + 4y + 6z = 46、翅膀 2x + 0y + 4z = 26
  2. 立起空间直角坐标系（x 鸡、y 兔、z 蜻蜓），三个方程依次长成三个半透明平面（鸡色、兔色、蜻蜓色）
  3. 三个平面交于一点 (5, 3, 4)，红笔点标出；相机小幅环绕让交点读得出
- 字幕：「笼子里又飞进几只蜻蜓」「三个未知数，就需要三维空间」「每个方程是一个平面，三个平面交于一点」
- 数据：5 + 3 + 4 = 12；10 + 12 + 24 = 46；10 + 0 + 16 = 26；系数矩阵行列式 = 12 ≠ 0
- 收尾：相机转回正交俯拍，纸面落回桌上（保留该三维坐标系的数据，2g 复用）

### 1e 高中 · 向量（约 35s）

- 相机：翻页，正交俯拍
- 画面：
  1. 纸上画一张寻宝小地图：从起点往东 3 格、往北 2 格画出一根箭头，记作 $\vec a = (3, 2)$
  2. 第二根箭头 $\vec b = (1, 2)$ 从 $\vec a$ 的箭头尖接上，红笔画出首尾相连的合箭头 (4, 4)
  3. $\vec a$ 拉长成两倍 (6, 4)，标 $2\vec a$
- 字幕：「向量：带方向的箭头」「往东 3 步、往北 2 步，记作 (3, 2)」「两段路首尾相接，就是向量相加」
- 数据：(3,2) + (1,2) = (4,4)；2·(3,2) = (6,4)

### 1f 高中 · 回归直线（约 45s）

- 相机：同页平移到新的坐标纸区域，横轴「距离（公里）」0–6，纵轴「送达用时（分钟）」0–50
- 画面：
  1. 角上画一个外卖袋；100 个点逐批落下（示意数据）
  2. 一条直线从水平位置开始，一步步转动、平移（梯度下降式的小步），每个点到线的竖直距离画成一个红笔小方块，左上一根「总面积」条随之缩短，最后停住
  3. 纸上写印刷体 $\hat y = \hat b x + \hat a$，代入实算的两个数
  4. 横轴 3.2 处竖一条虚线到直线，标签「预计 28 分钟送达」
  5. 红笔把 100 个点圈成一团，箭头指向 $\hat b$、$\hat a$ 两个数
- 字幕：「外卖：怎么预计送达时间？」「找一条线，让这些小方块总面积最小」「课本里叫它：回归直线」「100 单记录，被压成了 2 个数」
- 数据：示意数据按「用时 ≈ 6 + 6.9·距离 + 噪声」生成，固定种子；动画终点 = 最小二乘解析解（误差 < 1e-3）；总面积逐步单调下降；ŷ(3.2) 四舍五入 = 28
- 说明：这段同时给下集埋伏笔（「压成 2 个数」= 压缩；「挪直线让面积变小」= 训练），此处不点破

### 1-post 喘息（约 20s）

- 相机：慢慢拉远，看到整本数学本
- 画面：本子自后往前慢慢倒翻一遍，每页只留下直的东西发亮（1c 的两条线、1d 的平面、1e 的箭头、1f 的回归线），其余淡去；最后这些直线叠在同一页上
- 字幕：「它们有个共同点：都是直的」「数学里，这叫「线性」」
- 声音：只留弦垫与翻页声

### 2a 再看笼子（约 45s）

- 相机：翻到大学草稿纸，正交俯拍；左半页缩小保留 1c 的两线交点图
- 画面：
  1. 右半页画坐标系：横轴「头」0–40，纵轴「脚」0–100（纵轴 1 格 = 4 只脚，两轴单位不同时在轴上写明）
  2. 一只鸡跳出来，变成一根鸡色箭头 (1, 2)；一只兔变成兔色箭头 (1, 4)
  3. 23 根鸡箭头从原点首尾相接，逐根加速；接着 12 根兔箭头接上，尖端落在 (35, 94)，红笔圈出
  4. 左右两图并排停 2s：左边是「横着看」（两线交点），右边是「竖着看」（凑箭头）
- 字幕：「再回到笼子，换个角度看」「一只鸡 = 1 个头 + 2 只脚：一根箭头」「23 根鸡箭头，接上 12 根兔箭头」「正好走到 35 个头、94 只脚」
- 数据：23·(1,2) + 12·(1,4) = (35, 94)
- 声音：钢琴 + 低音垫；每接一根箭头一声，音高随序号升

### 2b 抽出系数（约 30s）

- 相机：固定
- 画面：
  1. 纸上原样写出 1b 的大括号方程组
  2. 系数 1、1、2、4 从方程里浮起，排成 2×2 方块，加上括号；x、y 竖排到右边成一列，35、94 成另一列，得到印刷体 $\begin{pmatrix}1&1\\2&4\end{pmatrix}\begin{pmatrix}x\\y\end{pmatrix}=\begin{pmatrix}35\\94\end{pmatrix}$
  3. 第一列染鸡色、第二列染兔色，分别连线到 2a 的鸡箭头、兔箭头
