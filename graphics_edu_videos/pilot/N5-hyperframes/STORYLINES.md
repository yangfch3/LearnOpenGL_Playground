# N5 纯 2D 剧情探针：方向备选

目的：给纯 2D 剧情找一个好案例并沉淀经验。不沿用四季与图形学主题。

选题标准：只有平面才讲得出的故事。3D 做不到、或做了反而变差的手法，才算 2D 的本事。候选手法：

- 图底关系：同一条轮廓，两边各是一样东西
- 线：一根线就是全部世界
- 画框：漫画格、对话气泡、拟声字本身就是道具
- 声即画：音频采样直接画出图形

共同前提（沿用 N2–N4）：60–80s，1920×1080 / 60fps，无旁白，程序化声音，代码绘制，确定性输出。

## 1. 风格菜单

可与第 2 节任一故事搭配，表中「适配」只是建议。

| 风格 | 参照 | 观感 | 实现 | 适配 | 风险 |
|---|---|---|---|---|---|
| 双色负形 | Saul Bass、Noma Bar、马蒂斯剪纸 | 冷静、机巧、海报感 | SVG 两块填充，由一条边界函数决定 | A | 角色只有剪影，情绪全靠姿态 |
| 单线连续 | La Linea（Cavandoli）、毕加索光绘 | 轻快、幽默、极简 | 一条定长折线，按弧长重采样形变 | B | 拉线形变不自然，全片就垮 |
| 孔版套色（Riso） | 独立出版物、Tom Haugomat | 温暖、颗粒、复古 | 2–3 个专色层 + 颗粒 + 套色错位，统一后处理 | 可叠加在 A/B/C 上 | 颗粒与错位经平台压缩可能糊，要重压测试 |
| 报纸连环画 | Peanuts、Ben-Day 网点、Chris Ware | 怀旧、好笑 | SVG 线稿 + 大网点 + 泛黄纸 | C | 网点太细会出摩尔纹 |
| CRT 荧光矢量 | 示波器音乐（Jerobeam Fenderson）、Vectrex | 冷、迷幻 | 按音频采样画线 + 余辉累积 | D | 单色单线，表现力上限低 |
| 逆光剪影 | Lotte Reiniger、皮影 | 古典、童话 | 黑剪影 + 彩色半透明背景层 | 任意 | 稳妥，但新意不足 |

我的倾向：负形或单线这类「规则即风格」的画法，风格本身就是故事的机制（风格规范 §6.1-12）。Riso 质感适合作为可选的叠加层，不单独成立。

## 2. 故事方向

### A「另一半」（推荐）

- 规则：画面被一条线分成上白下黑。线上住着黑色小人「墨」，线下倒立住着白色小人「纸」。**你的山就是我的谷**：线向上鼓，墨看到的是山，纸看到的是坑
- 每段看清一样东西：地面原来是另一个人的天空 → 突然出现的山，是对方在挖井 → 那棵树的倒影是另一棵树 → 红果是唯一同时属于两边的东西
- 首尾同帧：开场线在画面下方，只看得到墨的世界；结尾同一构图，线下那一窄条里多了倒垂的白树树干，还有贴着墨脚底的纸的脚底
- 声音：墨的世界在高音区，纸的世界演同一旋律的倒影（音程上下翻转，即复调里的镜像）；结尾两条合成一段镜像卡农

| 镜 | 时段 | 景别 / 运镜 | 画面 | 声音 |
|---|---|---|---|---|
| 1 | 0–5 | 全景，固定 | 一条水平线，线上鼓起一个小包，包里站起墨，伸懒腰。观众以为下面的黑色只是土地 | 风声，一个木琴音 |
| 2 | 5–15 | 全景，横移跟随墨 | 墨散步、浇他的小花。脚下忽然升起一座小山把他绊倒，他狐疑地踩了踩 | 高音区脚步；起山时地下传来闷响 |
| 3 | 15–22 | 推近线下，画面旋转 180°（全片第一次用强手法） | 黑色变成天空，白色变成地面，倒立的纸正在挖井：墨脚下那座山，就是她的井 | 同一旋律在低音区以倒影出现 |
| 4 | 22–36 | 中景，线居中 | 互相捣乱：墨把山铲平，纸的井被填上；纸再挖，墨再铲。两人都恼了，同时跺脚，脚底隔着线对上 | 上下两声跺脚落在同一拍，合成一个和弦 |
| 5 | 36–46 | 近景 | 墨敲三下地面，纸回三下。一问一答，节奏渐渐连成旋律 | 敲击音高上下互为倒影 |
| 6 | 46–60 | 中景，缓慢拉开 | 墨种下一颗红种子（全片唯一的彩色），它向上长成黑树，向下长成白树。墨浇上半，纸浇下半 | 原型与倒影第一次同时奏响 |
| 7 | 60–70 | 近景 | 红果从枝头落下，碰到线没有停，穿过去落进纸手里 | 穿线时音乐停半拍 |
| 8 | 70–80 | 全景，回到开场机位 | 两人走到树下，脚底对脚底站定；画面再转 180° 回到开场那帧，已分不出谁在上面 | 镜像卡农完整一遍，收在同一个和弦 |

- 可选彩蛋（难度高）：末镜继续拉远，整条线的起伏其实是两张相对的侧脸（鲁宾杯）。需要先设计大尺度轮廓，再倒推全片的山和井
- 2D 独有：图底互补只在平面成立；180° 旋转是 2D 摄像机最强的一招，全片只用两次
- 工程：整个世界是一个高度函数 h(x, t)，两边的形状自动互补；空间校验只需查角色是否贴线，是 N4「一个世界、一条规则」的 2D 版
- 风险：倒立小人要在镜 3 一次教会观众；只有剪影，表演全靠姿态与节奏

### B「一根线」

- 规则：全片只有一根线，从第一帧到最后一帧不断，**总长不变**。想画新东西，只能拆旧的
- 看清：线头是一个人 → 天黑了，是因为他拆了太阳 → 她身上的每一笔都来自他的世界
- 首尾同帧：同一条地平线、同一个太阳；开场地平线上是房子、树和一个人，结尾是两个牵手的人
- 声音：笔尖沙沙，音高随画线速度变；每画出一样东西响一个音，拆掉时同一个音倒放

| 镜 | 时段 | 景别 / 运镜 | 画面 |
|---|---|---|---|
| 1 | 0–6 | 全景，固定 | 白纸，线头从左边进来，一笔画出地平线、房子、树、太阳，最后线头卷成一个小人 |
| 2 | 6–16 | 全景，跟随笔尖横移 | 他开门、靠树、晒太阳；一对鸟（也是这根线的一段）互相绕着飞过 |
| 3 | 16–26 | 中景 | 他想画个伴，伸手拽太阳：太阳一圈圈解开，被拉成直线拖到身边，天暗下来 |
| 4 | 26–40 | 中景，镜头顺着被拉动的线走 | 拆树、拆屋顶，一段段线被拉过来画出另一个人，还缺一只手，四周已经什么都不剩 |
| 5 | 40–48 | 近景 | 他解开自己的左臂，补成她的手 |
| 6 | 48–58 | 近景 | 她睁眼，看见他少了一只手，想把自己的长发解下还他，却不够 |
| 7 | 58–68 | 中景 | 两人牵手，两只手合成一笔，省下一截线。这截线从握着的手里升起，卷成一个小太阳 |
| 8 | 68–75 | 全景，回到开场机位 | 同一条地平线，太阳小了一点，房子和树都不在了，地平线上站着两个牵手的人 |

- 2D 独有：线即物质，「拆东墙补西墙」能直接画出来
- 工程：构建时断言线的总长守恒；形变按「拉绳」模型做，即线沿自身滑动，而不是逐点插值（否则会糊成一团）
- 风险：手艺最重。拉线形变是否好看，要先做 10s 样片验证

### C「第五格」

- 规则：漫画语言就是物理。格子间的白缝隔开不同时刻，对话气泡、拟声字、汗滴、速度线都是能拿在手里的东西
- 看清：这个笑话已经演过无数遍（纸边磨损） → 头顶的气泡能当伞 → 页边空白也能画
- 首尾同帧：同一张四格漫画的整页；结尾右下角多了一格歪歪扭扭的第五格
- 声音：每个拟声字落地都有实体声（「哗啦」砸在气泡上会弹开）；翻页声即重读

| 镜 | 时段 | 景别 / 运镜 | 画面 |
|---|---|---|---|
| 1 | 0–5 | 全景，整页固定 | 一张泛黄的四格漫画，镜头推进第一格 |
| 2 | 5–20 | 按阅读顺序逐格推移 | 照剧本演一遍：出门 → 乌云，「轰隆」 → 大雨「哗啦」，头顶冒出「！」 → 浑身湿透的漫画哭脸 |
| 3 | 20–28 | 拉回整页，再推进第一格 | 重读，再演一遍。到第三格，她第一次没照剧本走，抬头盯着那个「！」 |
| 4 | 28–40 | 近景 | 她抓住自己的气泡撑在头顶，「哗啦」砸上去碎成笔画 |
| 5 | 40–50 | 中景，跨格横移 | 第四格里她是干的，但画好的哭脸还在等她，格框开始抖。她跨过白缝，从第四格下边框走出去 |
| 6 | 50–62 | 全景，页边空白 | 空白里什么都没有。她把第四格的边框拉直、折成新方框，拿速度线当笔画出太阳和草地 |
| 7 | 62–72 | 拉远，回到开场机位 | 还是那张四格，右下多出第五格，她坐在太阳底下，屁股下是雨字堆成的椅子 |

- 2D 独有：格框、白缝、气泡都是平面印刷物，放进 3D 就没意思了
- 与本系列的关系：最贴近教学片的核心能力「文字艺术化、文字即动效」，沉淀的经验最能迁移
- 风险：拟声字要进文本表，换语言时笑点要重做；好笑与否取决于表演节奏

### D「八度」（最实验的一个）

- 规则：**画面就是声音**。左声道是 x，右声道是 y，听到的就是看到的（示波器 XY 模式）。音程越和谐，图形越稳
- 看清：乱麻是不和谐 → 每次图形定住，都是两个声音对上了 → 完全一样，反而没有形状
- 首尾同帧：漆黑屏中一个绿点
- 声音：成片音轨就是画面的数据，声画同源做到极致

| 镜 | 时段 | 景别 / 运镜 | 画面 |
|---|---|---|---|
| 1 | 0–4 | 固定 | 漆黑示波屏中一个绿点，无声 |
| 2 | 4–14 | 固定 | 点颤动成线，再张成圆（纯音）；圆一压一弹，像在呼吸 |
| 3 | 14–24 | 固定 | 另一个声音进来，图形缠成乱麻，拍频嗡嗡作响 |
| 4 | 24–44 | 固定，偶尔微推 | 两个声音互相试探，音高滑动；每经过 5:4、4:3、3:2，图形突然定成对称的结，随即滑开又乱 |
| 5 | 44–56 | 推近（全片唯一一次推） | 滑到 1:1，成了同一个圆；相位渐渐对齐，圆压扁成一条斜线：两个声音完全一样，形状就没了 |
| 6 | 56–66 | 拉回 | 其中一个声音升高八度，2:1，一个稳定的 ∞ |
| 7 | 66–70 | 固定 | ∞ 慢慢收回成开场那个点，余辉散去 |

- 想留下的一句话：「不必一样，差一个八度也很好」（不上屏）
- 风险：没有角色，情感全靠音乐与图形；纯音听久了累；细亮线经平台压缩会糊，线宽和辉光要单独调

## 3. 推荐与对比

| | A 另一半 | B 一根线 | C 第五格 | D 八度 |
|---|---|---|---|---|
| 2D 独有程度 | 高 | 高 | 高 | 高 |
| 情感 | 强 | 强 | 中（喜剧） | 弱，偏抽象 |
| 工程风险 | 中 | 高 | 中 | 中 |
| 能迁移到教学片的经验 | 2D 摄像机、图底构图 | 线条形变 | 文字即动效 | 声画同源 |

- 首推 A：一条规则、一个世界，与 N4 成功的原因相同；画面机巧，又有温度
- 如果更看重给教学片攒经验，选 C
- 风格可单独选：例如 A 用双色负形叠 Riso 颗粒，C 用报纸网点

## 4. 本片要沉淀的 2D 经验

- 2D 摄像机：中心、缩放、旋转作为一组参数插值，对应 3D 那套做法
- 质感层：纸纹、网点、颗粒统一走一层后处理，还是逐元素用 SVG filter（N3 用的是后者），两者比一次
- 2D 空间校验：形状用多边形精确检查接触、包含、穿越，比 3D 的地面占地更严
- 无五官角色：剪影或单线角色怎样只靠姿态和节奏表演
