# N5「另一半」SPEC

故事方向见 [STORYLINES](STORYLINES.md) A；样片（镜 2–3）已认可，整片在其基础上延展。

## 1. 规则

- 世界只有一条边界 y = h(x, t)：线下墨色、线上纸色。墨站在墨色地面上，纸倒立在纸色地面上
- 一方的「有」是另一方的「无」：纸挖坑 = 墨那边起山；墨踩平山 = 纸的坑被填上；一方跺脚，线向对方鼓一下；两人同时跺同一点，力抵消，线不动
- 墨只存在于纸色区域，纸只存在于墨色区域（绘制即裁剪），两人永不互相遮挡
- 红色不属于任何一边：种子、果子能穿过线；在线两侧受的「重力」都指向线，所以最后停在线上
- 2D 转身 = 横向压扁再展开（纸片翻面）

- 鲁宾杯：杯身半宽 w(y) 由控制点三次插值，杯口 |x| < 8 处就是 h(x)；拉远前任何镜头都看不到杯沿（check.mjs 校验）
- 运动模糊：镜头快动时按画面每帧位移取 1–16 个子帧，在半帧快门内平均（成片里两次旋转峰值 48、34 px/帧）

- 强手法：两次 180° 旋转（段 3、段 9），同向，合起来转满一圈
- 与 STORYLINES 的差异：种子由纸递给墨（第一次穿线），果子由墨的树落向两人（第二次）；结尾两人隔着果子碰手，不再脚底对脚底（那一下已用在段 4）

## 4. 声音

- 墨：高音区木琴；纸：低音区拨弦。动机 E G A G E D C 与它以 C 为轴的音级倒影 A F E F A B C
- 听的位置跟随镜头旋转角：哪一侧朝上，哪一侧的声音就清楚，另一侧隔着地面变闷
- 敲击即旋律：墨的每一下取动机下一个音，纸取倒影；树生长与结尾时两条同时奏响（镜像卡农）
- 红色物体穿线时，音色在木琴与拨弦之间切换

## 5. 校验（check.mjs，逐帧 30Hz）

- 翻转前纸的身体与种子全在可见窄条以下
- 同时跺脚那一刻两人前脚 x 相差 ≤ 0.02
- 树（含树枝、树叶）与同侧角色的距离 ≥ 0.08，不粘连
- 手到铲柄、手到目标的偏差；所有关节为有限值
- build.py 断言：行走速度 ≤ 1.2、时间轴递增、坑深序列合法
