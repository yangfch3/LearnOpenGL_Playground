# N4「分辨率」SPEC

故事见 [N2 STORYLINES.md](../N2-hyperframes/STORYLINES.md) C。时刻全部由 `build.py` 算出，此处只列结构。

## 核心手法

整片只有一个 3D 世界、一台摄像机。四季的画风是同一个世界走过一条越来越完整的渲染管线，而不是四套美术：

| 季 | 管线状态 | 由此被「看清」的东西 |
|---|---|---|
| 春 | 光栅分辨率 16×9 起逐次翻倍（盒式滤波下采样 + 调色板量化） | 世界的轮廓、主角 |
| 夏 | 全分辨率 + MSAA，无光照平涂，正交投影 | 猫（一块橙斑）、集市人群（一团杂色） |
| 秋 | 打开方向光与阴影 | 麦田（平涂下是一条黄带） |
| 冬 | 正交 → 透视（滑动变焦），摄像机第一次旋转；雾 | 纵深：远山、树林、背面 |

- 摄像机：一个连续参数族，`k = 1/视距`，k = 0 即正交；变焦时保持主体平面的画面高度不变
- 世界规则：风一律自右向左（风筝、麦浪、落雪同向）；主角始终是红色

## 镜头

| 段 | 景别 | 内容 |
|---|---|---|
| 开场 | 全景（固定） | 16×9 色块，红块眨眼 |
| 春 | 全景（固定） | 分辨率逐拍翻倍，裂变从主角处扩散；男孩出门、看蝴蝶、停在一块橙斑前；矢量到来，镜头第一次推近：橙斑是只睡着的猫 |
| 夏 | 全景 → 摇 → 中全景 | 猫跑向集市，人群显形；女孩放风筝失败，男孩帮她放起 |
| 秋 | 中全景 → 中景 | 光打开，麦田显形，风筝的影子掠过麦浪；三人坐在树下看日落 |
| 冬 | 中景 → 透视 → 环绕 360° | 落雪，堆雪人；滑动变焦出纵深，镜头绕雪人一圈 |
| 尾声 | 全景（固定） | 男孩回家；画面逐级降回 16×9，色块退回开场那一帧，红块再眨眼；色块变成半透明网格叠在冬景上，逐格对位；片名由粗到细显影 |

## 声音

- 音乐：同一主题贯穿，音频「分辨率」随画面升级：春为方波，采样率随画面翻倍；夏为干声马林巴；秋加混响；冬为钢琴与弦垫、宽声场。结尾退回方波
- 音效：程序化合成；春天的音效同样降采样。每次翻倍一声高一个八度的「裂」，回落时依次降八度

## 画面

- 低多边形平涂；四季各一套色板，春天的调色板量化取自当季全部材质色
- 字：只有春天的分辨率计数（JetBrains Mono）与片尾片名（Noto Sans SC）
- 禁用：发光粒子、一律淡入上滑、无来由的镜头运动
