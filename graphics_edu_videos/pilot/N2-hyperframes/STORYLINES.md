# N2 剧情探针：三个故事方向

目的：测剧情短片的上限。覆盖 2D + 3D、四季、景别变化、建筑、植物、动物、人群与配角、主角在不同空间做不同的事；基调治愈，带一点哲理。

共同前提：

- 时长 75–90s，1920×1080 / 60fps，无旁白
- 无背景音乐（沿用系列约定），只用程序化合成的环境声与动作音效
- 画面不沿用教学片的深色底配色，另定一套四季配色，只用于剧情
- 全部用代码绘制、渲染结果确定，不用付费素材或 AI 生成画面

## B「慢递」（推荐：覆盖最全、最能测 2D 与 3D 的衔接）

- 手法：一个人一天的日常，跨越一年；镜头在一个世界里飞行
- 世界：一座悬浮在云上的低多边形小岛（3D）。岛上有小镇、钟楼、河、桥、一棵大树、田地和码头。镜头每绕岛转一段就换一个季节；推进窗户、店铺时，进入 2D 的室内场景
- 主角：骑自行车的年轻邮差。配角：面包店老板、钓鱼的老人、等信的小女孩、赶集的人群。动物：跟着邮差跑的小狗、鸭群、候鸟、冬天的鹿
- 观众看到的：邮差一年到头送信，有一封写给小女孩的信总是「还没到」。冬天的最后一班船上，信终于到了，原来是她自己春天写给明年的自己的
- 想留下的一句话：「有些东西走得很慢，但一直在路上」
- 开头 2 秒：俯拍的云海里，小岛缓缓转入画面；岛上钟楼敲响第一声，一群鸽子飞起
- 节拍：远景，春天的岛 → 中景，邮差出门、狗跟上 → 近景，女孩投信，信封写着「明年春天」 → 夏天，集市人群，穿过 2D 店铺 → 秋天，落叶、收割、老人钓鱼 → 冬天，雪夜、码头最后一班船 → 特写，信封打开 → 镜头拉到全岛远景，第二年的春芽冒出 → 片尾字
- 景别：远景（全岛环绕）→ 全景（街道）→ 中景（人物对话）→ 近景（手、信封）→ 特写（邮戳、叶脉、雪花）
- 画面：低多边形平涂，四季各一套主色（春樱粉、夏湖蓝、秋杏黄、冬雾蓝），2D 室内用同一套配色的剪纸感插画
- 声音：鸟鸣、自行车铃、集市人声、落叶、雪地脚步、船鸣、钟声贯穿四季

## A「种子」

- 手法：主角一年里的一个个瞬间；同一个形状不动，周围的场景全换掉（匹配剪辑）
- 世界：以 2D 插画为主。阳台、街道、图书馆、海边、雪夜车站，每个空间是一幅横移的长卷；3D 只出现在一处：一颗种子从土里长成树的生长过程
- 观众看到的：女孩春天在阳台花盆里种下一颗种子，之后忙着上学、旅行、搬家，再也没看过它。第二年春天，老邻居发来一张照片：花盆里长出了一棵小树
- 想留下的一句话：「你没在看的时候，它也在长」
- 开头 2 秒：特写，一颗种子落进手心；镜头一推，它变成了窗外的太阳
- 节拍：种下 → 圆形匹配剪辑串起四季（种子 → 太阳 → 西瓜 → 灯笼 → 雪球）→ 搬家，花盆留在原处 → 老邻居浇水的配角线 → 照片 → 片尾字
- 画面：水彩纸纹理的平面插画，长卷横移，用视差层出景深
- 声音：翻书、雨声、风铃、搬家纸箱、相机快门

## C「分辨率」（大胆的一个）

- 手法：世界本身在讲道理，用同一画面重组的形式
- 世界：开场整个世界只有 16×9 个像素，主角是一个色块。每过一个季节，世界的分辨率翻倍：春天是像素画，夏天变成矢量平面，秋天出现光影，冬天变成完整的 3D 场景
- 观众看到的：一个小像素人在越来越清晰的世界里行走、交朋友，发现原本以为的一块色斑，其实是一只猫、一片麦田、一群人
- 想留下的一句话：「看清这个世界，需要一点时间」；和本系列讲的光栅化、分辨率直接呼应
- 开头 2 秒：满屏 16×9 的大色块，其中一块眨了眨眼
- 节拍：像素春天 → 分辨率翻倍的转场（像素裂开成更小的像素）→ 矢量夏天的集市 → 有光影的秋天 → 3D 冬天，镜头第一次旋转 → 回看开场，那些色块是同一片风景 → 片尾字
- 风险：前半段受像素画风格所限，「优美」要等到后半段才出来
