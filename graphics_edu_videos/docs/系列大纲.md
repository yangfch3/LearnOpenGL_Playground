# 系列大纲

- 共 38 集，每集 5–10 分钟（按 7 分钟计约 4.4 小时），讲透一个机制；篇序即依赖序
- 分季制作：第一季为第一至三篇（14 集，约 1.6 小时），之后按反馈与单集成本决定后续
- 「仓库 demo」指 `source_core/vsproj/LearnOpenGL/` 下的文件；「补」= 仓库无对应 demo 的补充内容
- 「数学」列只标超出初中的部分；向量单独成集（2.1），矩阵在 2.2 讲，积分直觉在 PBR 篇就地补
