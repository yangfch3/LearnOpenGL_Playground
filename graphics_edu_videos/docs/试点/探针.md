## P2 矩阵乘向量（20s，取材 2.2）

平移矩阵 T 第 4 列为 (2, 1, 0, 1)，其余为单位阵；点 p = (1, 1, 0, 1)，结果 (3, 2, 0, 1)

| 时间 | 画面 | 画面文字 |
|---|---|---|
| 0–5 | 公式 T · p = ?，T 下标「平移矩阵」，p 下标「点」 | 「把点 (1, 1, 0) 右移 2、上移 1」 |
| 5–9 | 第 1 行与 p 逐项高亮相乘：1·1 + 0·1 + 0·0 + 2·1 = 3 | — |
| 9–13 | 第 2 行：0·1 + 1·1 + 0·0 + 1·1 = 2 | — |
| 13–15 | 第 3、4 行直接出结果 0、1 | — |

- 考察：逐项高亮与项移动、中文与公式同行混排（基线、字号、字体一致）；Manim 版文字烘焙在片段内，记为「换语言需重渲」
- 实现：HyperFrames（KaTeX）、Manim（MathTex + xeCJK）各一版

## P3 Phong 光照球（15s，取材 3.2）

两版参数完全一致：

- 球：半径 1，经纬细分 64 × 32，中心原点；物体色 (1.0, 0.5, 0.31)
- 相机：位于 (0, 0.8, 4) 看向原点，竖直视场角 45°
- 点光源：白色；θ = 2π · t / 12，位置 (2cos θ, 0.8, 2sin θ)；画成半径 0.08 的纯白小球，参与深度测试
- Phong 逐片段计算：环境 0.1、漫反射 1.0、镜面强度 0.5、光泽度 32；无衰减
- 不做 gamma 校正（3.4 集才引入）；MSAA 4×；背景透明
- 时间：0–12s 光源绕一周，12–15s 停留

| 版本 | 输出 |
|---|---|
| WebGPU | 在 HyperFrames 合成内直接渲染 |
| 原生 OpenGL | 带透明通道的视频片段（格式实现时定，须 HyperFrames 可读） |

- 考察：同一时刻两版逐像素差异统计、高光形状、边缘抗锯齿、渲染耗时、确定性

## C 混用合成（10s）

在 HyperFrames 中叠三层：

| 层 | 内容 |
|---|---|
| 底 | HyperFrames：bg 底色 + 标题文字 |
| 中 | P3 原生 OpenGL 片段的 0–10s |
| 上 | Manim 片段（透明背景）：P2 的结果 p′ = (3, 2, 0, 1)，2s 时淡入 |

校验图案（每层各画一份，位置错开）：

- 一个 80×80 的 gl-orange 色块
- 帧号条码：8 个方块按二进制编码本层帧号（白 = 1），可机器读取

验收：

- 透明边：半透明边缘无黑边、白边（检查预乘）
- 帧对齐：三层帧号逐帧相同
- 色彩：三个色块解码后 RGB 各分量差 ≤ 2
