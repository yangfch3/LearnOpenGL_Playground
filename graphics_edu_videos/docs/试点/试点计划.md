# 试点计划：你好，三角形

## 1. 目的

- A 工具探索：用 1.1 的代表镜头 + 第一季探针比较候选工具，锁定合成与文字层，定出第一季的真实效果层方案
- B 生产验证：用选定工具完整制作 1.1（成片即[系列大纲](../系列大纲.md)第 1.1 集），校准阅读时长、编码与观看效果
- 1.1 的内容与讲法见 [1.1 知识点](../1.1_你好三角形/知识点.md)、[1.1 分镜](../1.1_你好三角形/分镜.md)

## 2. 共同前置

1. 环境：已就绪，基线见 [README](../../README.md)；HyperFrames 自带 headless shell 下 `data-requires-webgpu` 渲染通过（硬件 device）
2. 分镜细化：补全全集每镜画面文字与时长，连同 3.2 的探针 → 我审核（技术准确性审核点）。初稿：[1.1 分镜](../1.1_你好三角形/分镜.md)、[探针](探针.md)

## 3. A 段：工具探索

### 3.1 候选与剪枝

| 层 | 参测 | 不测 / 后备 |
|---|---|---|
| 示意图与文字 | HyperFrames、Manim CE | Motion Canvas：以 Canvas2D 为主，与 HyperFrames 定位重叠，自定义 shader 支持未核实 |
| 合成 | HyperFrames | Remotion：HyperFrames 走不通时启用，镜头内 WebGPU 代码基本可迁移 |
| 真实效果 | WebGPU（嵌入 HyperFrames）、原生 OpenGL 离线渲染 | — |

### 3.2 测试内容

探针每个 10–20 秒，只用于测工具，不进成片。细节见[探针](探针.md)。

| 编号 | 内容 | 考察 | 实现 |
|---|---|---|---|
| S1 | 1.1 镜头 1 管线地图 | 文字排版、转场 | HyperFrames / Manim 各一版 |
| S7 | 1.1 镜头 7 光栅化 | 网格、逐个计数、音效同步 | 同上 |
| P1 | 探针：3D 视锥 + 相机环绕（取材 2.4） | 3D 示意、相机运动 | 同上 |
| P2 | 探针：矩阵乘向量逐项展开（取材 2.2） | 公式动画、中文与公式混排 | 同上 |
| P3 | 探针：Phong 光照球体，光源绕行（取材 3.2） | 真实效果层 | WebGPU / 原生 OpenGL 各一版 |
| C | Manim 片段（带透明通道）与原生 OpenGL 片段导入 HyperFrames 合成一段 | 混用衔接：透明通道、帧对齐、色彩一致 | HyperFrames |

### 3.3 公平规则

- 同一份分镜文字、同一模型、同一[风格规范](../风格规范.md)
- 每镜返工上限 3 轮，超过记为「未达标」

### 3.4 记录表（每个工具 × 每个镜头一行）

| 项 | 记法 |
|---|---|
| AI 首版 | 可直接用 / 小改 / 重写 |
| 返工轮数 | 达到验收所需轮数 |
| 中文与公式排版 | 1–5 分，附截图 |
| 渲染耗时 | 每分钟 1080p60 成片所需分钟数 |
| 确定性 | 同输入渲染两次，逐帧哈希是否一致 |
| 调试 | 预览 / 热重载、报错可读性、Windows 环境问题 |
| 代码量 | 行数、依赖体积 |
| 文本外置 | 文字从文本表读取的难易；只改表能否直接重渲 |

### 3.5 决策

- 合成与文字层：本段锁定，整个系列沿用（换工具等于重做全部镜头与风格组件）
- 示意图层：可混用（如 Manim 只做公式），前提是 C 通过
- 真实效果层：只定第一季方案；计算、阴影等第二季能力在第二季开工前另做探针
- 结论与记录表回写预研文档第 3 节

## 4. B 段：生产验证

1. 用选定工具实现全集（A 段胜出的 S1、S7 直接复用）
2. 抽帧审核 → 音效 → 出片
3. 观看检查：阅读时长校准、平台码率重压后画质、小屏可读、抽帧盲测
4. 回写预研文档：阅读时长参数、60fps 单集渲染耗时、单集成本
5. 拆分预研文档：已定约束（输出规格、音效、选型等）并入工程约定 / 风格规范，其余归档

## 5. 验收

- A 段：记录表填完，各层结论有依据；C 无透明边、错帧、色差
- B 段：
  - 时长 5–10 分钟，规格符合预研文档 7.5（1920×1080 / 60fps）
  - 静音可懂：未看过分镜的人看完，能按顺序说出各阶段做了什么
  - [1.1 知识点](../1.1_你好三角形/知识点.md)第 3、4 节的数据与出入项在画面中全部正确
  - 无黑帧 / 旧帧，音效落点准确，任意 1 秒内闪烁不超过 3 次
