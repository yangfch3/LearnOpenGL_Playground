# LearnOpenGL 系列规范（草案）

LearnOpenGL 图形学教学正片专用的视觉方案与目录约定。通用的数值底线见[风格规范](风格规范.md)，本文只写这个系列自己的选择。系列目标与集目见[预研](基于LearnOpenGL的图形学教学视频预研.md)、[系列大纲](系列大纲.md)。

## 1. 底色与颜色原则

- 深色底：久看不刺眼，GL 画面（多为深色清屏）嵌入不突兀
- 颜色只承载语义，同一颜色全系列含义不变；强调靠明暗，不另设强调色
- 实现时导出为 `shared/style/` 下的变量文件（CSS 变量 / Python 常量），镜头内不写死数值（A 段 S1 开工时建）

## 2. 配色

对比度为对 `bg` 的 WCAG 实算值，门槛见风格规范 §1。

### 2.1 中性色

| 名 | 值 | 用途 | 对比度 |
|---|---|---|---|
| bg | #11161D | 视频底色（Manim 默认纯黑，须改为此值） | — |
| surface | #1B222C | 卡片、代码卡、面板 | — |
| line | #2E3947 | 装饰分隔线、示意网格；不承载信息 | 1.55 |
| disabled | #5A6577 | 可选 / 未使用的阶段；只用在 bg 上（surface 上仅 2.72） | 3.08 |
| ink-dim | #9AA6B8 | 次要文字、坐标轴、图注 | 7.37 |
| ink | #EDF1F7 | 主文字、焦点 | 16.02 |

- 非焦点元素降到 40% 不透明度：ink 降后对比度 3.53，仍可辨

### 2.2 语义色

| 名 | 值 | 含义 | 对比度 |
|---|---|---|---|
| shader | #FF7AC8 | 可编程阶段与着色器 | 7.67 |
| discard | #F25050 | 丢弃、被裁掉、错误；必配 ✕ 或虚线 | 5.22 |

- 原始数据（顶点数组、字节）用中性色，不着色

### 2.3 坐标空间色

色相沿管线顺序推进（紫 → 黄），2.3 集起成套使用；1.1 只用 NDC 与窗口。

| 空间 | 值 | 对比度 |
|---|---|---|
| 局部 | #C49BFF | 8.20 |
| 世界 | #7FA7FF | 7.67 |
| 观察 | #45C4E0 | 8.84 |
| 裁剪 | #4FD6A6 | 9.95 |
| NDC | #A6DB5C | 11.16 |
| 窗口 | #E8D45A | 12.10 |

- 相邻空间色差偏小（OKLab ΔE：NDC–窗口 0.087，局部–世界 0.095），同屏时必须带文字标签

### 2.4 画面内容色

画面「里」的 GL 渲染结果，按代码中的值直接换算，不调色、不入语义。

| 名 | 值 | 来源 |
|---|---|---|
| gl-orange | #FF8033 | 片段颜色 (1.0, 0.5, 0.2)；0.5 取 128 |
| gl-clear | #334D4D | 清屏色 (0.2, 0.3, 0.3) |

- 画面只标浮点值（理由见 [1.1 知识点](1.1_你好三角形/知识点.md) §5），十六进制值仅供渲染
- gl-clear 对 bg 仅 2.0：GL 画面区域加 2px ink-dim 边框
- gl-orange 与 discard 色差 ΔE 0.111，同屏时丢弃必须配 ✕ / 虚线

## 3. 字体与字号

| 用途 | 字体 | 许可 |
|---|---|---|
| 中文与正文 | Noto Sans SC（可变字重） | OFL 1.1 |
| 代码、数值 | JetBrains Mono | OFL 1.1 |
| 公式 | HyperFrames 用 KaTeX，Manim 用 LaTeX 默认字体（同源 Computer Modern 字形） | 待核实 |

- Manim 中文经 xeCJK 指定 Noto Sans SC，不用 ctex 在 Windows 下默认的宋体；两套公式渲染是否需统一，P2 探针后定

| 级别（1080p 下 px；初值，试点 B 段按小屏校准） | 字号 / 字重 | 用途 |
|---|---|---|
| 标题 | 72 / 700 | 章节卡、镜头标题 |
| 正文 | 44 / 400 | 说明文字 |
| 标注 | 36 / 500 | 图注、坐标、代码卡 |
| 下限 | 32 / 500 | 仅限数字、短标签 |

## 4. 图形

- 通过 / 丢弃：通过保持原样，需要时配 ink ✓；丢弃用 discard ✕ 后淡出
- 坐标轴：ink-dim，带箭头与轴名；不用 RGB 三色轴（与语义色冲突）
- 卡片圆角 12px
- 管线图：

| 阶段 | 填充 | 边框 |
|---|---|---|
| 可编程 | shader 15%（#352537，ink 字对比度 12.59） | 3px shader |
| 固定 | surface | 3px ink-dim |
| 可选 / 未用 | 无 | 3px disabled 虚线 |

- 代码卡：surface 底，JetBrains Mono 36px；单色 ink，注释 ink-dim，不做多色高亮（避免与语义色冲突）；当前行 = 行底提亮 + 左侧 4px ink 竖条
- 每段代码配一句白话，放在代码卡下方，用正文字号
