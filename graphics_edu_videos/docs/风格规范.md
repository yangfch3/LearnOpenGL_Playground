# 风格规范（草案）

- 适用全系列，HyperFrames 与 Manim 共用；数值以本文为准
- 实现时导出为 `shared/style/` 下的变量文件（CSS 变量 / Python 常量），镜头内不写死数值

## 1. 原则

- 深色底：久看不刺眼，GL 画面（多为深色清屏）嵌入不突兀
- 颜色只承载语义，同一颜色全系列含义不变；强调靠明暗，不另设强调色
- 颜色不作唯一信息通道：必配文字标签、形状或线型（照顾色弱，也抗 yuv420p 色度抽样）

## 2. 配色

对比度为对 `bg` 的 WCAG 实算值。门槛：承载信息的文字 ≥ 4.5:1，图形 ≥ 3:1。

### 2.1 中性色

| 名 | 值 | 用途 | 对比度 |
|---|---|---|---|
| bg | #11161D | 视频底色（Manim 默认纯黑，须改为此值） | — |
| surface | #1B222C | 卡片、代码卡、面板 | — |
| line | #2E3947 | 装饰分隔线、示意网格；不承载信息 | 1.55 |
| disabled | #5A6577 | 可选 / 未使用的阶段；只用在 bg 上（surface 上仅 2.72） | 3.08 |
| ink-dim | #9AA6B8 | 次要文字、坐标轴、图注 | 7.37 |
| ink | #EDF1F7 | 主文字、焦点 | 16.02 |

- 非焦点元素降到 40% 不透明度：ink 降后对比度 3.53，仍可辨

### 2.2 语义色

| 名 | 值 | 含义 | 对比度 |
|---|---|---|---|
| shader | #FF7AC8 | 可编程阶段与着色器 | 7.67 |
| discard | #F25050 | 丢弃、被裁掉、错误；必配 ✕ 或虚线 | 5.22 |

- 原始数据（顶点数组、字节）用中性色，不着色

### 2.3 坐标空间色

色相沿管线顺序推进（紫 → 黄），2.3 集起成套使用；1.1 只用 NDC 与窗口。

| 空间 | 值 | 对比度 |
|---|---|---|
| 局部 | #C49BFF | 8.20 |
| 世界 | #7FA7FF | 7.67 |
| 观察 | #45C4E0 | 8.84 |
| 裁剪 | #4FD6A6 | 9.95 |
| NDC | #A6DB5C | 11.16 |
| 窗口 | #E8D45A | 12.10 |

- 相邻空间色差偏小（OKLab ΔE：NDC–窗口 0.087，局部–世界 0.095），同屏时必须带文字标签

### 2.4 画面内容色

画面「里」的 GL 渲染结果，按代码中的值直接换算，不调色、不入语义。

| 名 | 值 | 来源 |
|---|---|---|
| gl-orange | #FF8033 | 片段颜色 (1.0, 0.5, 0.2)；0.5 取 128 |
| gl-clear | #334D4D | 清屏色 (0.2, 0.3, 0.3) |

- 画面只标浮点值（理由见 [1.1 知识点](1.1_你好三角形/知识点.md) §5），十六进制值仅供渲染
- gl-clear 对 bg 仅 2.0：GL 画面区域加 2px ink-dim 边框
- gl-orange 与 discard 色差 ΔE 0.111，同屏时丢弃必须配 ✕ / 虚线

## 3. 字体

| 用途 | 字体 | 许可 |
|---|---|---|
| 中文与正文 | Noto Sans SC（可变字重） | OFL 1.1 |
| 代码、数值 | JetBrains Mono | OFL 1.1 |
| 公式 | HyperFrames 用 KaTeX，Manim 用 LaTeX 默认字体（同源 Computer Modern 字形） | 待核实 |

- 字体文件只在 `shared/fonts/` 放一份（LFS），不依赖系统安装；项目里的引用方式见[工程约定](工程约定.md) §1
- Manim 中文经 xeCJK 指定 Noto Sans SC，不用 ctex 在 Windows 下默认的宋体
- 两套公式渲染是否需统一，P2 探针后定

### 3.1 字号（1080p 下 px；初值，试点 B 段按小屏校准）

| 级别 | 字号 / 字重 | 用途 |
|---|---|---|
| 标题 | 72 / 700 | 章节卡、镜头标题 |
| 正文 | 44 / 400 | 说明文字 |
| 标注 | 36 / 500 | 图注、坐标、代码卡 |
| 下限 | 32 / 500 | 仅限数字、短标签 |

- 彩色文字 ≥ 36px 且字重 ≥ 500（彩色细字经色度抽样易糊）
- 行高 1.4；一屏说明文字 ≤ 2 行、≤ 30 字

## 4. 线条与形状

- 承载信息的线 ≥ 3px，网格线 ≥ 2px，禁止 1px（平台重压后消失）
- 实线 = 实际存在；虚线 = 可选、假设、被裁掉的部分
- 点（顶点、像素中心）直径 ≥ 12px；卡片圆角 12px
- 通过 / 丢弃：通过保持原样，需要时配 ink ✓；丢弃用 discard ✕ 后淡出
- 坐标轴：ink-dim，带箭头与轴名；不用 RGB 三色轴（与语义色冲突）
- 管线图：

| 阶段 | 填充 | 边框 |
|---|---|---|
| 可编程 | shader 15%（#352537，ink 字对比度 12.59） | 3px shader |
| 固定 | surface | 3px ink-dim |
| 可选 / 未用 | 无 | 3px disabled 虚线 |

## 5. 版式

- 内容区：左右各 96px，上 80px，下 120px（避开进度条）；关键信息不出内容区
- 代码卡：surface 底，JetBrains Mono 36px；单色 ink，注释 ink-dim，不做多色高亮（避免与语义色冲突）；当前行 = 行底提亮 + 左侧 4px ink 竖条
- 每段代码配一句白话，放在代码卡下方，用正文字号

## 6. 动效

无旁白时，动效既承担讲解，也决定趣味。画面要多动起来，但每个动作都要讲得出理由。

### 6.1 原则

1. **从机制出发**：先想清楚这一步在机制上发生了什么，再设计动作。动作的方向、先后、快慢、数量要与真实机制相符
2. **不暗示错误事实**：讲解需要的顺序或节奏与实际不同时（如 GPU 实际并行，画面逐个演示），在画面中注明，或在后续镜头纠正
3. **因事设计，不套模板**：手法跟着具体内容和镜头情绪走；已用过的手法不是默认选项，同一手法不在相邻镜头重复，一集之内要有变化
4. **有来有去**：元素的出现、变化、离开都有交代，观众能一直追住同一个对象；少用凭空出现、凭空消失
5. **有主有次**：同一时刻只有一个焦点；节奏有起伏，关键结论处给停顿和强调
6. **宁缺毋滥**：说不出理由的动作不加，好看但干扰理解的动作删掉
7. **同屏文字要少**：标签、注解、字幕合起来计算同屏文字量；只留当下要读的，其余用完即退或降为非焦点
8. **点到为止**：演示到观众看懂就收，不为「完整」把过程演满；趣味优先于完整
9. **让观众跟得上**：画面与视角的每次变化都要让观众知道看向哪里、为什么变；短时间内剧烈、频繁、没有来由的变化让人疲惫、抓不住重点
10. **世界可信**：画面中的事物遵守它所在世界的规则，除非打破规则本身就是要表达的内容

### 6.2 默认参数

镜头需要时可以调整。

| 类型 | 时长 | GSAP 缓动 |
|---|---|---|
| 入场 | 0.5s | power3.out |
| 退场 | 0.3s | power2.in |
| 强调 | 0.25s | power2.out；放大 ≤ 1.08 倍或提亮 |
| 镜头转场 | 0.6s | power2.inOut |

- 整屏静止超过 3s 要有理由（如留给阅读）；`hyperframes check` 的 `dead_stretch` 只是提醒
- Manim 对应的 rate_func 在 A 段 S1 定

### 6.3 底线

- 任意 1 秒内闪烁 ≤ 3 次；大面积亮度变化须 ≥ 0.3s 渐变，禁止全屏闪白
- 需要「随机」效果时用固定种子，保证每次出片相同

## 7. 阅读时长（初值，试点 B 段校准）

- 文字停留 ≥ max(2s, 1s + 字数 × 0.25s)
- 字数：汉字各计 1；连续的英文字母、数字、小数点、下划线合计 1（如 `0.5`、`GL_TRIANGLES`）；标点、空格、运算符不计
- 公式每多一项 +0.5s
- 从文字完全出现起算，到它发生下一次变化止
