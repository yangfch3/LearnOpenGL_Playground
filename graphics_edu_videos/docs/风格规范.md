# 风格规范

适用于所有片子的数值底线，HyperFrames 与 Manim 共用。底色、配色、字体等视觉方案每部片（或每个系列）自己定，写在它的 SPEC 或系列规范里；怎么讲、怎么拍、怎么写见[创作原则](创作原则.md)。

## 1. 颜色

- 对比度对片子的底色实算（WCAG）：承载信息的文字 ≥ 4.5:1，图形 ≥ 3:1；不达标就加深或提亮，不改语义
- 颜色只承载语义，同一颜色在一部片（或一个系列）里含义不变；强调靠明暗，不另设强调色
- 颜色不作唯一信息通道：必配文字标签、形状或线型（照顾色弱，也抗 yuv420p 色度抽样）

## 2. 文字

- 1080p 下画面文字一般 ≥ 36px，32px 是下限，只给数字、短标签；彩色文字 ≥ 36px 且字重 ≥ 500（彩色细字经色度抽样易糊）
- 行高 1.4；一屏说明文字 ≤ 2 行、≤ 30 字
- 字体文件只在 `shared/fonts/` 放一份（LFS），不依赖系统安装；许可须允许入库与商用，附许可文件；引用方式见[工程约定](工程约定.md) §1

## 3. 线条与形状

- 承载信息的线 ≥ 3px，网格线 ≥ 2px，禁止 1px（平台重压后消失）
- 实线 = 实际存在；虚线 = 可选、假设、被裁掉的部分
- 点直径 ≥ 12px

## 4. 版式

- 内容区：左右各 96px，上 80px，下 120px（避开进度条）；关键信息不出内容区
- 动作安全框 90%、标题安全框 80%：画面内容在前者内，字幕与标题卡在后者内

## 5. 动效

### 5.1 兜底参数

没有更好的理由时才用。同一片里所有动作都用这一套，节奏就会千篇一律。

| 类型 | 时长 | GSAP 缓动 |
|---|---|---|
| 入场 | 0.5s | power3.out |
| 退场 | 0.3s | power2.in |
| 强调 | 0.25s | power2.out；放大 ≤ 1.08 倍或提亮 |
| 镜头转场 | 0.6s | power2.inOut |

- 整屏静止超过 3s 要有理由（如留给阅读）；`hyperframes check` 的 `dead_stretch` 只是提醒

### 5.2 底线

- 任意 1 秒内闪烁 ≤ 3 次；大面积亮度变化须 ≥ 0.3s 渐变，禁止全屏闪白
- 快动：60fps 下峰值超过约 15px/帧、画面又有大块深浅对比时加运动模糊；峰值不超过约 48px/帧
- 需要「随机」效果时用固定种子，保证每次出片相同

## 6. 阅读时长

这是下限：字幕停留不得短于它。时间线由画面动作排，字幕挂到动作上，不用阅读时长去排时间线。

- 文字停留 ≥ max(2s, 1s + 字数 × 0.25s)
- 字数：汉字各计 1；连续的英文字母、数字、小数点、下划线合计 1（如 `0.5`、`max_value`）；标点、空格、运算符不计
- 公式每多一项 +0.5s
- 从文字完全出现起算，到它发生下一次变化止

## 7. 声音

- 综合响度 −20 LUFS（±1），真峰值 ≤ −1 dBTP；成片后用 ffmpeg ebur128 实测，不达标调总增益重出
