# 创作原则

所有片子通用的创作经验，人与 AI 共用；某个系列自己的选择写在该系列规范里。每条写「做什么」和「为什么」，数值只作参考。阶段关口见[制作 CheckList](制作CheckList.md)，数值底线见[风格规范](风格规范.md)，工具与已验证做法见[工程约定](工程约定.md)。

原则管方向，不管样子：两部片照着同一套原则做，也应当长得不一样。§7 的手法是工具箱，不是默认选项。

## 1. 讲述

1. **先定观众带走什么**：写一句话，作为全片的验收标准。没有这一句，段落会凭「这个也重要」进片，最后成了一份清单
2. **一条线贯穿**：一个例子、一条规则或一个人物目标从头带到尾，每段让它换一种样子。新东西挂在旧东西上，观众始终知道「这还是那件事」
3. **一段只推进一步，讲透为止**：删掉不影响那一句话的段。长度由讲透需要的步数定，不为凑时长加戏，也不为压时长删步骤；讲不完就拆集。演示到观众看懂就收，不为「完整」演满
4. **从观众已有的东西出发**：按观众熟悉的顺序与难度递进，不按年代或学科体系平铺。平铺让全片又平又难跟
5. **节奏要有起伏**：关键结论处给停顿；大段之后留几乎无字、镜头慢、音乐留白的喘息，让人回味，也给继续看的理由。高潮放在最能串起前文的地方。不套固定的段落顺序：每片套同一个模板，就是同一种呼吸
6. **开头就给理由**：前 10 秒有一样让人想看下去的东西（反差、悬念、好看的画面），首帧不是黑屏或空景。铺垫段各留一个指向它的伏笔，否则铺垫像复习课

## 2. 画面

7. **形式即内容**：先想清这一步在机制上发生了什么，再让画面怎么变本身去讲它。动作的方向、先后、快慢、数量与真实机制相符；说不出在演什么的动作，再好看也删
8. **一身兼几职**：最好的装置让一个动作同时是两三种表示，观众会在这里「啊」一声。每多一种只为好看的变化，就多一处要对齐的接缝
9. **对应要看得见**：同一个东西有两种表示时，让两处同时被强调或同步运动。观众自己去连线往往连不上，还会怀疑画错了
10. **有来有去**：出现、变化、离开都有交代，观众能一直追住同一个对象。离开画面要走出去、被收走或放下，不凭空消失
11. **一个焦点，而且够大**：同一时刻只有一个焦点。取景跟着焦点走，让它占住画面的主要部分；用完的东西退场或变淡，底纹退到很浅。物体要么整个在画内，要么整个在画外，不被画框切一半。观众一眼注意不到的小窗、小字，等于没有
12. **镜头为主体服务**：观众始终看得清主角是谁、在做什么，道具与前景不挡关键信息。每次运镜说得出理由（跟着一个东西走，去看下一个焦点）；景别跟着动作走。大推近、环绕、大变焦放在画面第一次值得这样看的时刻，不设次数配额；短时间内频繁、没有来由的变化让人疲惫
13. **变化连续、有起点**：能用参数连续变化表达的（颜色、光照、分辨率、投影），不用切换和叠化；变化从焦点处起始、向外扩散，视线自然落在焦点上
14. **世界可信**：先定世界规则（比例、方向、谁能做什么），画面中的事物遵守它，物体不互相穿过。打破规则只在打破本身就是要讲的内容时
15. **精度与造型匹配**：造型的写实程度不超过能控制住的精度。简洁的造型让小误差不显眼，越写实，每处误差越刺眼
16. **不暗示错误事实**：讲解需要的顺序或节奏与实际不同时（如实际并行、画面逐个演示），在画面中注明或稍后纠正
17. **快动要连得上**：每帧位移过大时，深浅分明的大块形状会一帧一跳，像掉帧。按每帧位移限速，超出就加运动模糊（做法见工程约定 §3）

## 3. 文字

无旁白时，文字就是讲述者的声音。

18. **字少，只讲画面讲不出的那句**：标签、注解、字幕合起来算同屏文字量，只留当下要读的。一条字幕一件事；算式、坐标、读数写在画面里，跟着过程变
19. **按角色换形式**：说明、承上启下、插一句话的旁白，字体、位置、出场方式各不相同。同一种样式从头用到尾，观众很快就不读了
20. **长在画面里**：文字落在它说的东西旁边，或写在画面世界的表面上；跟着动的东西走时，移动平稳、字形不乱变，内容变化慢到读得清。图例、说明贴着它所指的东西，不堆在主区域。词怎么出现、怎么变，本身也可以演示它说的事
21. **点题**：概念被命名的那一刻，字幕里与画面里的同一个词用同一种醒目处理，之后再出现也认得
22. **用观众的话**：不用制作时的内部词，标签与进度提示写成完整的普通说法（课本小节标题那样的名词短语）
23. **平实陈述，不写腔调**：字幕是讲述者在正常讲解，不是广告语。套路一多，观众读出的是「文案」，会怀疑内容也是套出来的
    - 问句只留给画面里真有待回答的问题
    - 不用：设问后自答；「不是…而是…」；「其实」「说穿了」「揭晓」「秘密」式的揭秘口吻；凑出来的排比、对仗；用逗号硬断出停顿感；把机制说成拟人小故事的俏皮比喻
    - 自查：念给一个人听，像不像讲课时会脱口说出的话；去掉修辞后意思不变，就去掉

## 4. 声音

24. **声画同源**：声音与画面由同一张时间表驱动，画面的结构变化在声音里有对应，闭眼也能感到段落
25. **声音挑着配**：只给观众该注意的动作配声，需要专注的段落里少而轻。频繁的质感音（书写、摩擦）压低、去掉刺耳的高频，用只有缓慢起伏的低频声；关键一拍的静音也是声音
26. **音乐给专注让路**：需要看懂、读懂的段落里，音乐只作底，低于动作音，和弦慢起慢收、相邻交叠；完整的旋律留给开场、收尾、喘息

## 5. 剧情片

27. **找一条世界本身在变的规则**：故事沿着它推进。观众看懂规则就会预期下一步，每次兑现都是一次满足
28. **每段给一个被看清的对象**：每段都有一样东西从模糊变清楚。发现感比情节密度更撑得住无旁白的片子
29. **配角线短而完整**：起因、受挫、帮忙、结果四拍即可，每拍一个动作
30. **2D 的规则从平面本身找**：图底关系、线、画框、裁切只在平面上成立；2D 去模仿 3D 的纵深与光影，处处不如 3D
31. **揭示要守住**：结尾揭示世界更大的样子时，把揭示物的范围写进数据，逐帧校验之前的镜头都看不到它
32. **世界不必大，但要看得清**：主要地点尽量放进主镜头一帧之内，人物在各景别都看得清；故事真需要远方时再放大，接缝照样要校验

## 6. 科普片、教学片

33. **先找本质，再找物件**：先想清数学或机制上发生了什么，再找一个日常物件让它自己演出来。没讲到本质的动画是装饰
34. **老熟人原样出现**：课本里的记号、写法、名称照搬，观众一眼认出「这个我学过」。新名词在观众看懂那件事之后才出现，作为它的名字
35. **数要真算，比喻守边界**：演示的结果由构建脚本实算并断言；类比用有出处、偏保守的措辞，说「像」不说「就是」，有争议的说法选不会被挑错的版本；写不出出处的数字不上画面
36. **离观众远的不硬凑**：要额外铺垫半天才讲得通，或与主线只是「也用到了」的关系，宁可删掉
37. **并列的内容用同一套讲法，由易到难**：几个并列的应用按同一组步骤讲，观众到第三个时已能预期下一步；最难的放最后，前一个学到的说法能用在后一个。借的是讲法，不是把某个概念硬套进每个应用；各步的分量按内容定，不必等长
38. **不给观众分级**：不出现「小学」「初中」这类学段字眼，学段靠画面暗示
39. **行业与品牌**：多家并列、只用文字名，不用 logo，不让一家代表整个行业

## 7. 手法库（可选，不是默认）

用过就在探针记录的手法表里记一笔；上一部片用过的，下一部不默认再用，要用先说出这次的新理由。

| 手法 | 适合 | 代价 / 风险 |
|---|---|---|
| 首尾同一帧（或倒放回开场） | 想让观众自己发现「一切开始得多朴素」 | 连着几部都这样收尾，就成了套路 |
| 一个世界演到底（一张桌、一本书、一片山谷） | 接缝少、比例前后一致 | 世界的样子会限制题材；选它是因为合适，不是因为省事 |
| 进度提示（便签、目录、小标题） | 并列的长段落需要脚手架 | 常驻会抢视线；只在换步时看一眼 |
| 标题卡、手写批注 | 大转折、插一句话 | 用多了像 PPT |
| 回扣上一段或上一集的画面 | 新内容挂在旧画面上 | 观众没看过前文时要能独立成立 |
| 首次推近 / 首次环绕作为高潮 | 画面细节第一次值得看 | 其余地方因此不敢动，镜头一路远拍 |
| 一个主题旋律贯穿，音色随段落加厚 | 段落感、首尾呼应 | 每片都是同一种配乐结构 |
