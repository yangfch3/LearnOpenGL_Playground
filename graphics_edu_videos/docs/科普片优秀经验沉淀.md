# 科普片优秀经验沉淀

无旁白科普片、教学片要让观众真正「看懂」的经验。通用原则见[风格规范](风格规范.md) §6 与[工程约定](工程约定.md)黄金准则，世界、镜头、角色的做法可借[剧情片优秀经验沉淀](剧情片优秀经验沉淀.md)；本文只记科普片特有的部分。示例与数值只作参考；具体案例记在[探针记录](试点/探针记录.md)。

## 1. 目标与取舍

- **先写一句「看完能说出……」**：用观众自己的话写，作为全片的验收标准。每段再写一句「本质」，写不出来的段不进片。不先定这一句，段落就会凭「这个也重要」进片，最后成了一份名词清单
- **讲透比讲全重要**：一段只推进一步，一个概念讲到观众自己想通为止。每段塞两三个概念再配一个应用，观众记住的只是名词
- **离观众远的不硬凑**：一个领域要额外铺垫半天才讲得通，或者和主线只是「也用到了」的关系，宁可删掉。删掉的是覆盖面，换来的是看懂
- **长度由讲透要的步数定**：不为压时长省掉步骤；讲不完就拆集，每集各有完整的起落

## 2. 结构

- **从观众已有的东西出发**：按观众学过的顺序、按难度递进铺垫，不按学科发展史排。按年代平铺会让全片又平又难跟；历史只在一两处点到（出处、回望）
- **一个例子贯穿全片**：选一个人人见过的具体例子（一道应用题、一张照片），从头带到尾，每段让它换一种表示。新知识挂在旧知识上，观众始终知道「这还是那件事，只是换了看法」
- **老熟人原样出现**：课本里的记号、写法、名称照搬，观众一眼认出「这个我学过」。新名词只在观众看懂那件事之后出现，作为它的名字。片名讲的东西，片中要一再看到它熟悉的样子
- **钩子在前 10 秒**：首帧就是观众日常里的东西，开头抛出一个反差（熟悉的旧东西和最前沿的新东西，原来是同一回事）。铺垫段每段都留一个指向钩子的伏笔，否则铺垫会像复习课
- **节奏要有呼吸**：铺垫 → 喘息 → 递进 → 高潮 → 喘息 → 应用。大段之后留 15–25s 几乎无字、镜头慢、音乐留白的段落，让人回味；顺便预告下一段要看什么，给继续看的动力
- **高潮放在最能串起前文的地方**：选最反直觉、又能一下子解释前面几件事的那个演示（参考：一个反例同时说明了几何上的压扁、代数上的无解、早年学过的平行线）
- **并列的应用用同一套讲法**：如「整体图景 → 怎么造出来 → 怎么用 → 规模 → 揭开面纱」。到第三个应用时观众已能预期下一步，讲法本身就成了理解的脚手架。借的是讲法，不是把某个概念硬套进每个应用
- **应用按难度递增**：最难、最震撼的放最后。由易到难，前一个应用里学到的说法能直接用在后一个
- **首尾相接**：结尾回到起点（如快速倒放回开场那一帧），让观众自己发现一切开始得有多朴素

## 3. 演示

- **先找本质，再找物件**：先想清这一步在数学或机制上发生了什么，再找一个日常物件让它自己演出来（参考：天平演「等号两边去掉一样的还相等」）。没有讲到本质的动画，再好看也是装饰
- **最好的装置一身兼几职**：同一个动作同时是两三种表示（一个日常动作 = 一步代数运算 = 一次几何变形），观众在这里会「啊」一声
- **一个装置配一个本质**：不是每处都要动画；说不出某个动画在讲什么，就删掉（风格规范 §6.1-6、12）
- **多种看法并排**：同一件事的两种看法（如代数与几何）同屏出现，对应处同时强调（风格规范 §6.1-18）
- **数要真算**：例子里的数字由构建脚本实算并断言，演示的结果必须真的成立（迭代真的收敛、拟合真的最优）。示意数据在画面角落标「示意」
- **比喻守住边界**：类比用有出处、偏保守的措辞，说「像」不说「就是」；学界有争议的说法选不会被挑错的版本。数字只用有公开出处的，写不出出处的不上画面
- **行业与品牌**：多家并列、只用文字名，不用 logo，不让一家代表整个行业

## 4. 文字

字幕的通用规则见风格规范 §6.4，科普片另有几条：

- **不给观众分级**：字幕不出现「小学」「初中」这类学段字眼。观众的学制、年龄不一，这些词还带着「这很初级」的意味；学段靠画面暗示（如纸的样式）
- **一条字幕一个概念**：算式、坐标、读数写在画面里，不进字幕
- **结构提示用问句**：讲法的步骤要上画面时，写成观众会问的完整问句（「它是怎么做出来的？」），不写制作时的内部词（「图景」「造」）

## 5. 流程

1. 目标一句话 → 列出观众已有的锚点 → 每段写「锚点 / 本质 / 装置」一张表 → 与用户敲定 → 分集写 SPEC（每段画面动作、字幕原文、画面上的字、实算数据、声音落点）
2. SPEC 阶段建事实核实清单，逐条查到出处再动手
3. 先做高潮段的样片：它最能检验装置是否讲到了本质
4. 看片后按下面的清单自查

## 6. 自查清单

- 有没有哪段只是报出名词加一个应用？
- 有没有哪段删掉也不影响「看完能说出」那一句？
- 观众在哪些地方能认出自己学过的东西？片名讲的东西出现了几次？
- 前 10 秒有没有一个让人想看下去的反差？
- 大段之后有没有喘息？
- 每个动画能不能用一句话说出它在演什么本质？
