# 试点：你好，三角形

## 1. 目的

- A 工具探索：用 1.1 的代表镜头 + 第一季探针比较候选工具，锁定合成与文字层，定出第一季的真实效果层方案
- B 生产验证：用选定工具完整制作 1.1（成片即[系列大纲](系列大纲.md)第 1.1 集），校准阅读时长、编码与观看效果
- 内容：LearnOpenGL「你好，三角形」的渲染管线概览：三个顶点经两个最简着色器，变成屏幕上一个纯色三角形
- 不含：EBO 与矩形、线框模式、课后练习（归入 1.2）；着色器编译 / 链接的 API 细节只一笔带过

## 2. 受众与前置

- 数学：平面直角坐标系、一次函数、比例（初中）
- 编程：不要求。代码只作画面元素，每段代码配一句白话

## 3. 依据

- 教程：[LearnOpenGL CN · 你好，三角形](https://learnopengl-cn.github.io/01%20Getting%20started/04%20Hello%20Triangle/)
- 代码：`source_core/vsproj/LearnOpenGL/simple_draw/hello_triangle.cpp`
- 规范：OpenGL 4.6 Core 中 Primitive Clipping、Coordinate Transformations（含视口）、Basic Polygon Rasterization、Per-Fragment Operations 各节；概览参考 OpenGL Wiki [Rendering Pipeline Overview](https://www.khronos.org/opengl/wiki/Rendering_Pipeline_Overview)

## 4. 知识点与严谨性

### 4.1 关键数据（出自 hello_triangle.cpp，画面数字以此为准）

| 项 | 值 |
|---|---|
| 顶点（NDC） | (-0.5, -0.5, 0)、(0.5, -0.5, 0)、(0, 0.5, 0) |
| 顶点数据 | 9 个 float = 36 字节；属性 0：每顶点 3 个 float，步长 12 字节，偏移 0 |
| 绘制调用 | `glDrawArrays(GL_TRIANGLES, 0, 3)` |
| 顶点着色器 | `gl_Position = vec4(aPos.x, aPos.y, aPos.z, 1.0)`：w = 1，透视除法后坐标不变 |
| 片段着色器 | `FragColor = vec4(1.0, 0.5, 0.2, 1.0)`，不透明橙色 |
| 清屏色 | (0.2, 0.3, 0.3)，深青 |
| 视口 800×600 | 窗口坐标 (200, 150)、(600, 150)、(400, 450)，原点在左下；按像素中心实算覆盖 60000 个像素（无压线）→ 6 万个片段，而顶点着色器只运行 3 次 |
| 示意网格 16×12 | 顶点落在 (4, 3)、(12, 3)、(8, 9)；覆盖 24 个像素，自下而上逐行 8 / 6 / 4 / 4 / 2 / 0；没有像素中心恰好压在边上，不涉及边界归属规则 |

### 4.2 与教程原文的出入（视频按规范讲）

| 教程原文 | 视频采用 |
|---|---|
| 裁切在片段着色器前执行，丢弃视图外的像素 | 裁剪的对象是图元，发生在光栅化之前，于裁剪空间（-w ≤ x, y, z ≤ w）进行；越界部分被切掉，可能切出新顶点 |
| 管线图中几何着色器位于图元装配之前 | 几何着色器的输入是已装配好的图元；本例未使用，画面中灰显为可选阶段 |
| 最后阶段为「Alpha 测试和混合」 | 逐样本操作：模板 / 深度测试、混合等；Alpha 测试在核心模式已移除。本例未开启深度测试与混合，颜色直接写入 |
| 片段是渲染一个像素所需的所有数据 | 片段是带数据的「候选像素」，之后仍可能被丢弃；本例无多重采样，一个片段对应一个像素 |
| 未说明像素如何判定被覆盖 | 补：单采样下，看像素中心是否落在三角形内 |

### 4.3 讲法定案

- 阶段顺序：顶点着色器 → 图元装配 → 裁剪 → 透视除法 → 视口变换 → 光栅化 → 片段着色器 → 逐样本操作。裁剪以图元为单位（点、线、多边形规则不同），必须先装配
- 颜色只用 0.0–1.0 浮点表示，不展示 8 位整数：0.5 × 255 = 127.5，规范只要求取最接近的两个整数之一，127 还是 128 由实现决定

| 5 | 图元装配与裁剪 | 三点按 GL_TRIANGLES 连成三角形；画出可视范围；插入「假如越界」：一个三角形被切成多边形；回到本例：全在范围内，无需裁剪；除以 w（= 1）得 NDC | 切割 | 0:45 |
| 6 | 视口变换 | 公式：x窗口 = (x + 1) / 2 × 宽，y 同理；代入 800×600 得三个窗口坐标；窗口原点在左下 | 数字滚动 | 0:45 |
| 7 | 光栅化 | 换 16×12 示意网格（标注「示意分辨率」）；像素中心点阵；把中心代入三条边的直线方程看正负，三边都在内侧才算覆盖；逐行扫描计数 8 / 6 / 4 / 4 / 2 / 0 = 24；切回 800×600：6 万个片段 | 每个片段一声，音高随行变化 | 1:40 |
| 8 | 片段着色器 | 代码卡片；红绿蓝三色光按 1.0 / 0.5 / 0.2 调出橙色，A = 1 表示不透明；全部片段同时上色；计数对比：顶点着色器 3 次 vs 片段着色器 6 万次 | 上色 | 0:50 |
